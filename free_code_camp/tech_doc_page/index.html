Introduction

What is HTML? (HyperText Markup Language, backbone of web pages).

Why it’s important for structuring web content.

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <p>Hello World!</p> </body> </html>
  • HTML defines the structure of web pages
  • Works with CSS for styling
  • Works with JavaScript for interactivity
HTML Elements

HTML elements are the building blocks of web pages.

Difference between opening and closing tags.

<h1>This is a heading</h1> <p>This is a paragraph</p>
  • <h1> – heading
  • <p> – paragraph
  • <div> – container
  • <span> – inline text
Attributes

Attributes give extra information about elements.

Common ones: id, class, href, src, alt.

<img src="image.jpg" alt="Description of image">
  • id → unique identifier
  • class → group of elements
  • src → source for media
  • href → link destination
Headings and Paragraphs

HTML provides 6 heading levels (<h1>–<h6>).

Paragraphs are added with <p>.

<h1>Main Title</h1> <h2>Subtitle</h2> <p>This is a paragraph explaining something.</p>
  • <h1> → largest heading
  • <h6> → smallest heading
  • <p> → normal text block
Lists

HTML supports ordered (<ol>) and unordered (<ul>) lists.

<ul> <li>Apples</li> <li>Bananas</li> <li>Cherries</li> </ul>
  • Unordered lists → <ul></ul>
  • Ordered lists → <ol></ol>
  • List item → <li></li>
Links and Images

Links are made with <a> and images with <img>.

Always use alt for images (accessibility).

<a href="https://www.example.com">Visit Example</a> <img src="photo.jpg" alt="A sample photo">
  • <a> → hyperlink
  • href → link URL
  • <img> → image tag
  • alt → text description
